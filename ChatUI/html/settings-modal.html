Backup & Restore

Full backup

Save all local ChatUI conversations, projects, attachments, Workspace data, settings, API configuration, and cached Read Aloud audio in one portable file.

Restore full backup

Validate a previous ChatUI backup, then replace this browser's current local ChatUI data after confirmation.

Workspace backup

Create a Workspace-only ZIP with the real folder tree, empty folders, and readable Markdown files. Chats and settings are not included.

Restore Workspace

Restore a validated ChatUI Workspace ZIP. Only Workspace data is replaced.

Full backup files contain private ChatUI data and may contain Gemini API keys. Workspace ZIP backups contain your Workspace Markdown content. Keep both private and only restore files you trust.
